# UpstreamBugReport

## Boundary

- Create one concise local Markdown draft.
- Never publish or mutate GitHub.
- Existing recorded tool, UI, event, log, or filesystem evidence suffices.
- Force no reproduction.
- The draft route executes no product binary and creates no comparison or reproduction route; a separate explicit product-verification request may use only generic `runner-exec`.
- The controller uses `RUST_LOG=error`.
- Missing locked or offline cache input stays Blocked.
- Use exact-binary and manifest evidence pending cache preparation.
- Never relax flags or fetch.
- Inspect implicated repository files, symbols, events, and commits once.
- Use the interval from 30 days before first observation through today, or the 30 days ending today when observation time is unknown.
- Omit cause and history without parent-diff proof.

## Evidence

- Include facts and a focused-check-proved mechanism.
- Name an in-window introducing commit only when its parent diff proves behavior.
- Omit speculation, rejected theories, and investigation narrative.
- Give the local draft separate Symptom, ProposedMechanism, RemainingUncertainty, and ExactDraftClaims sections when those sections have supported content.

## Draft And Handoff

- Use the frozen RouteEntry template, or fixed minimal order only if absent.
- Preserve exact ATX labels, order, and only reference or current-user label dispositions.
- CodexDoctor keeps its position and unfenced list body.
- Invent or offer no logs.
- Include title, minimum environment, symptom, decisive evidence, impact, sequence, expected behavior, and mandated facts/attribution; proved paths/history only when shorter than omission.
- Exclude private paths, identifiers, checkout disclaimers, related issues, speculation, rejected hypotheses, and defenses.
- State each fact once.
- End with the Codex CLI assistance sentence.
- Stay below 600 words excluding headings and raw evidence.
- Remove unsupported or duplicate text on reread.
- With path-derived ArtifactLock, NoReplace-create the exact absent canonical Markdown OwnedTarget below `$PROJECT_SCRATCH_ROOT`.
- Fsync the file and parent, release the lock, and return its path plus a concise summary.
